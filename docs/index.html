Filtre os achados e acesse o catálogo ou a análise de reinstalação quando a operação for elegível. As duas confirmações e o backup continuam obrigatórios.

O diagnóstico não comprova a causa de todos os erros, a validade do token ou a conectividade real. Teste o servidor antes de liberar jogadores.

GUIA DE MANUTENÇÃO

Do mundo de referência ao dedicado

  1. Prepare a origem

    Use o próprio dedicado para reparar ou editar os mods. Crie um mundo temporário somente se quiser copiar uma configuração de referência.

  2. Desligue o servidor

    Feche o jogo, os shards e qualquer reinício automático.

  3. Analise os clusters

    Selecione as pastas, os mundos e confira o plano sem alterações.

  4. Confirme duas vezes

    Revise a lista e autorize somente uma instalação exclusiva com UGC padrão.

  5. Valide antes de reabrir

    Leia os logs, preserve o backup e teste a entrada no mundo e nas cavernas.

SUPORTE

Perguntas frequentes

Qual arquivo devo baixar?

Use x64 na maioria dos PCs. x86 e ARM64 são alternativas quando compatíveis com o sistema e o servidor DST. Windows 7/8, Linux e macOS não são suportados; ARM64 ainda exige teste em hardware ARM.

O programa apaga meu mundo?

O aplicativo não edita saves diretamente e cria um backup. Entretanto, remover mods pode afetar entidades salvas quando o mundo for iniciado. Faça um backup externo e teste antes.

Funciona em instalações compartilhadas?

A manutenção automática não aceita instalações compartilhadas, UGC personalizado ou mods locais. Desligue o servidor e qualquer reinício automático.

Como verificar o SHA-256?

Baixe o SHA256.txt do mesmo release e compare com o resultado do PowerShell: Get-FileHash -Algorithm SHA256 .\Gerenciador-de-Dedicado.exe. Um hash não substitui assinatura digital.

Por que a versão permanece 1.0.0?

As revisões possuem identificadores de build próprios. A página consulta o GitHub para encontrar os arquivos publicados. Não há atualização silenciosa.
