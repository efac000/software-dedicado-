# Segurança

Não compartilhe tokens, backups, saves ou logs privados em issues públicas. Relate vulnerabilidades através de um canal privado do mantenedor. Para reprodução, use clusters fictícios e dados sanitizados.

Nenhum arquivo de servidor é enviado ao GitHub pelo programa. A consulta opcional à API Steam envia somente IDs de itens Workshop. O site consulta apenas releases públicos.

A instalação dedicada deve ser exclusiva e o servidor precisa estar desligado, inclusive qualquer watchdog/reinício automático. Caminhos UGC personalizados e mods locais não são suportados pelo reset. Teste em cluster descartável antes da produção. A aplicação não possui assinatura digital nesta fase. Confira o SHA-256 divulgado junto ao executável.
